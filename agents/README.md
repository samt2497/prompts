# Agents

Subagent definitions: a role, the tools it may use, and its instructions. Format follows Claude Code's `.claude/agents/*.md`, but the body works as a system prompt anywhere.

Install one: `cp agents/<purpose>/<name>.md .claude/agents/` (or `~/.claude/agents/` for all projects).
